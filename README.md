## Hosting

This is a static website. No build step or package installation is required.

To use GitHub Pages, upload these files to the root of a public repository. In **Settings → Pages**, select **Deploy from a branch**, **main**, and **/(root)**. Retain `.nojekyll`.

All asset links are relative, so the site also works from a repository subpath or another static host.
